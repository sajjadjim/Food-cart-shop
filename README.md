# 🍜 Sajjad JIM's Ramen Cart • 3D Interactive Shop

An interactive 3D Cyberpunk Food Cart and Ramen Bar experience built with **React**, **Three.js**, **WebGL**, and **GLSL Shaders** powered by **Vite**.

Developed by **[Sajjad JIM](https://sajjadjim.web.app)** (GitHub: [@sajjadjim](https://github.com/sajjadjim)).

## Features
- ⚛️ **Modern React Architecture:** Componentized with React (`<RamenCanvas />`, `<HudHeader />`, `<AboutModal />`, `<LoadingScreen />`, `<HudFooter />`).
- ⚡ **Vite Powered:** Instant Hot Module Replacement (HMR) and optimized build times (~400ms).
- 🌟 **Dynamic 3D Profile Textures:** In-game 3D screens dynamically render Sajjad JIM's profile, tech stack, and portfolio links.
- 🎮 **Interactive 3D Scene:** Arcade machines, vending machines, and holographic ramen bowl with bloom post-processing.
- 🔊 **3D Audio:** Immersive ambient ramen shop soundscape and interactive click audio.

## Setup & Running

Download [Node.js](https://nodejs.org/en/download/).
Run the following commands:

```bash
# Install dependencies
npm install

# Run the local development server (Vite)
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
